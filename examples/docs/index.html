FullScroll Demos

필요한 패턴을 고르고,
선언만 복사하세요.

FullScroll은 옵션을 많이 조합하는 도구가 아닙니다. 기본 구조를 만들고, 필요한 섹션에 fs-* 선언만 추가하는 방식으로 사용합니다.

먼저 이 구조로 시작

1. 기본 화면을 먼저 작성

모든 섹션은 기본적으로 세로 한 화면입니다. 가로나 예외 동작이 필요한 곳에만 속성을 붙이세요.

<main fs>
  <section>첫 화면</section>
  <section fs-horizon>
    <article>가로 1</article>
    <article>가로 2</article>
  </section>
  <section>마지막 화면</section>
</main>

작성 순서

세 단계면 충분합니다.

  • 일반 섹션부터 작성
  • 필요한 곳에 fs-* 선언 추가
  • 한 번만 초기화
new FullScroll('[fs]', {
  Swiper,
  dots: true
});
