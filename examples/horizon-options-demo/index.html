가로 옵션

다음 화면에서 fs-horizon-only를 확인하세요.

Only 1

좌우 키 또는 가로 스와이프로만 이 그룹 안을 이동합니다.

Only 2

위아래 휠·키·세로 스와이프는 이 슬라이드를 순회하지 않습니다.

Only 3

세로 입력은 바로 다음 또는 이전 세로 페이지로 이동합니다.

중간 세로 페이지

다음은 fs-horizon-first 데모입니다.

First 1

다른 세로 페이지에서 들어오면 항상 여기부터 시작합니다.

First 2

좌우로 세 번째까지 이동한 뒤 위아래로 나가 보세요.

First 3

다시 위아래로 돌아오면 첫 번째 슬라이드가 표시됩니다.

끝

두 속성은 함께 사용할 수도 있습니다.
